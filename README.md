# GN 2.0 — host your own

The whole GN 2.0 game site in **one file**, ready for you to host with **your own** Firebase.

- **`index.html`**: the site. Every stylesheet, script, config file and icon is packed inside it.
- **`SETUP.md`**: step-by-step instructions for hosting it and connecting your own Firebase.
- **`firestore.rules`**: the database security rules you paste into Firebase.

It works the moment you host it: games only, no setup. Follow **[SETUP.md](SETUP.md)** to add accounts, cloud saves, ratings, broken-game reports and the online counter, all running on your own free Firebase project.

Nothing in this file is connected to the original GN 2.0's Firebase, database, owner settings or admin tools. Your site, your players' accounts and your usage are entirely your own.

## How it's made

Don't edit `index.html` by hand (except the `GN_CONFIG` block on your own copy). It's generated by `build.py` from the GN 2.0 source:

```
python3 build.py <GN 2.0 source folder> index.html
```

A GitHub Action rebuilds it every 6 hours when GN 2.0 changes, so the newest version is always here. See "Updating your copy" in SETUP.md.
