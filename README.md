# GN 2.0 — single file

The whole [GN 2.0](https://github.com/SCHSwork/math) site in one file: **`index.html`**.

Every stylesheet, script, config file (game list pin, game info, partner games, owner settings) and icon is packed inside it, so you can:

- open it straight from your computer (double-click it, no server needed)
- host it anywhere that takes one HTML file
- send it to someone as a single download

Games, covers, accounts and cloud saves still load from the internet exactly like on the main site.

## Want to host your own?

Use **[`template/`](template/)** instead. It's the same single file, but with no Firebase project or owner settings from GN 2.0 built in. You add your own Firebase in one block at the top of the file. Follow [`template/SETUP.md`](template/SETUP.md).

## What's different from the main site

- **No service worker / offline cache.** Those need separate files, so they're left out. The site still works normally online.
- **No "install as app" manifest**, for the same reason.
- Opened from disk (`file://`), the browser keeps its own storage for that file, so favorites, recents and settings start fresh compared to the hosted site. Sign in to bring your cloud save over, or use Export / Import Data.

## How it's made

Don't edit `index.html` by hand. It's generated by `build.py` from SCHSwork/math:

```
git clone https://github.com/SCHSwork/math
python3 build.py math index.html                         # GN 2.0 itself
python3 build.py --template math template/index.html     # clean copy for others
```

A GitHub Action (`.github/workflows/build.yml`) does this every 6 hours and commits the new `index.html` and `template/` when the main site changes. You can also run it any time from the **Actions** tab → **Build single file** → **Run workflow**.
